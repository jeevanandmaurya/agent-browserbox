# Analysing data

1. Look before computing: read the first lines of the file and report its shape and columns.
2. Do the arithmetic in code (run_python with pandas when the Python pack is installed, otherwise run_js) — never estimate figures by eye.
3. State how missing or malformed values were handled.
4. Report the findings first, then the method. If a chart helps, build it as an HTML page and show it.
5. Save derived files next to the source and name them in the answer.
