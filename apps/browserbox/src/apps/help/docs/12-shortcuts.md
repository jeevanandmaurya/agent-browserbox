# Keyboard shortcuts

## Message box

| Keys | Does |
| --- | --- |
| Enter | Send (or queue, while the agent works) |
| Shift+Enter | New line |
| Shift+Tab | Switch mode: Ask first, Plan, Auto |
| Esc | Stop the agent |
| / | Commands |
| @ | Pick a file to include |
| ↑ ↓, Tab | Move through and choose from the command or file list |

## Terminal

| Keys | Does |
| --- | --- |
| ↑ ↓ | History |
| Tab | Complete commands and paths |
| Ctrl+C | Stop the running command |

## Desktop

| Keys | Does |
| --- | --- |
| Ctrl+K | Launcher |
| Double-click a title bar | Maximise or restore |

## Preview

| Keys | Does |
| --- | --- |
| Esc | Leave full screen |
